How it works

From setup to a clearer workday.

A short setup gives your team a practical view of the work already stored in Odoo.

STEP 01

Install the module

Add ara_community_gantt_view to your addons path, update the Apps List, and install it.

STEP 02

Set stage progress

Open Project → Configuration → Task Stages and set a Gantt Progress value for each stage.

STEP 03

Open your Gantt view

Use the Gantt menu, apply filters, and click any bar to open the task form.
